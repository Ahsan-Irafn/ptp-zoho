# Practical Training Pathways — 3CX Phone System Integration Guide

**Integration Type:** Server-Side REST XML Template  
**Compatible Versions:** 3CX Phone System **Version 18** and **Version 20**  
**Required Licence Tier:** **3CX Pro** or **3CX Enterprise / AI Edition**  
*(Note: 3CX Free and StartUP editions do NOT support custom server-side CRM integrations.)*  
**Timezone:** Australia/Adelaide (ACST / ACDT DST)  

---

## 1. Supported Capabilities

| Capability | Supported | Description |
| :--- | :---: | :--- |
| **Contact Lookup** | ✅ | Matches inbound/outbound caller numbers against normalized Australian numbers (`+614...` / `04...`). Displays candidate full name in 3CX WebClient & Desktop App. |
| **Screen-Pop Link** | ✅ | Generates authenticated URL `https://crm.pracpathways.com.au/contacts/{id}`. **Requires active CRM session and enforces role permissions.** Never contains bypass tokens. |
| **Call Journaling** | ✅ | Automatically logs call duration, direction, agent extension, status (answered, missed, busy, failed), and timestamps upon hangup. |
| **Click-to-Call** | ✅ | Agents initiate calls directly from assigned candidate records via the 3CX Web Dialer or `tcx:` desktop protocol. |
| **Agent Extension Mapping**| ✅ | Maps extension `101` &rarr; Ayesha Sohail and extension `102` &rarr; Maryam Touqeer. |
| **Missed Call Callbacks** | ✅ | Inbound missed calls automatically create high-priority callback tasks for the assigned calling agent. |

## 2. Server-Side Installation in 3CX Management Console

### Step 1: Download the Template
Obtain the pre-configured CRM template:
- Path in CRM repository: `3cx/ptp-3cx-crm-template.xml`
- Web Download: From the CRM Integrations Control Panel, click **Download XML**.

### Step 2: Upload to 3CX
1. Log in to your **3CX Management Console** with administrator credentials.
2. In the left navigation, open **Settings &rarr; CRM Integration**.
3. Click the **Add** or **Upload Template** button at the top.
4. Select `ptp-3cx-crm-template.xml`.
5. 3CX will register **Practical Training Pathways CRM**.

### Step 3: Configure Parameters
Under the newly added CRM integration configuration:
- **CRM Server URL:** `https://crm.pracpathways.com.au`
- **3CX Integration API Key (Bearer Token):** Enter the API key generated in CRM Integration Settings (`ptp_3cx_sec_...`).
- **Call Journaling:** Ensure **Enable Call Journaling** is checked.
- Click **OK** to save and apply.

## 4. Privacy, Security & Data Exposure

### Authentication & Protection:
- All 3CX requests require HTTP header `Authorization: Bearer <API_KEY>` or `X-API-KEY`.
- Rate limiting protects `/api/integrations/3cx/lookup` against phone enumeration attacks.
- Operational logs redact sensitive caller data.

### Screen-Pop Security:
The screen-pop link generated by the 3CX template points to `https://crm.pracpathways.com.au/contacts/{contact_id}`.
- If an agent is not logged into the CRM, they are prompted to authenticate.
- Once authenticated, role-based access control applies:
  - Calling agents can only access contacts assigned to them.
  - If Agent A answers a call for a candidate assigned to Agent B, the screen-pop enforces assignment isolation.

### Information Received by 3CX:
When 3CX performs a contact lookup, the PBX receives:
- Candidate Name (`firstname`, `lastname`)
- Company (`Practical Training Pathways`)
- Phone Number and Email Address
- Authenticated Contact URL

*No financial data, course pricing, or internal notes are transmitted to 3CX.*
